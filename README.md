# 指纹浏览器如何分配团队权限？

晚班客服需要接手德国店，店长希望他用自己的账号登录。**「指纹浏览器」** 可以把指定环境授权给团队，成员沿用共享配置，分别保留自己的网站登录状态。选团队工具时，值得让晚班同事亲自走一遍接班和退出项目的流程。

## 两种官方资料能回答什么

指纹浏览器的电脑端文档列出邀请成员、接受邀请、把单个环境授权给团队的步骤。成员使用共享的设备和网络配置，个人网站 Cookie 与网页存储各自保留。晚班客服首次打开后，应使用自己的业务账号登录。[团队共享说明](https://zwbrowser.com/help/desktop/teamwork/)

![桌面客户端的团队管理入口](https://zwbrowser.com/images/help-desktop-team.webp)

AdsPower 的套餐表分别列出环境数量和成员数量。询价时先填实际人数，再查看对应档位的团队功能。这能回答买几个席位，具体能否按项目限制成员，还要在实际角色设置里验证。[AdsPower 套餐对照](https://www.adspower.com/pricing)

![AdsPower产品展示](https://github.com/user-attachments/assets/d9cf60b3-2ea6-42e9-8a46-77ee610ea27f)

## 用两个环境验收一次完整交接

建立可公开演示的 A 店、B 店环境，只授权新成员使用 A 店。请成员从自己的客户端打开 A 店，记录网站是否要求登录，然后尝试查找 B 店。最终两边退出，管理员撤销 A 店的测试授权，成员刷新后再次检查。

把成员可见范围、可改字段、网站角色和撤权后能否重新打开分别记下来。同一行写清由浏览器管理员还是网站管理员处理，交班后出现问题才找得到负责人。
